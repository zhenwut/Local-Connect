# Local Connect

手机和电脑之间快速传输文本与 JPG 照片的局域网小工具。电脑运行 Python 服务，手机只需浏览器；电脑接收页可复制文本，并把一批照片合成 PDF。项目不需要安装第三方 Python 包。

## 启动

电脑需要 Python 3.9 或更新版本。在本目录运行：

```powershell
python server.py
```

终端会显示电脑接收页、手机发送页和本次访问码。两台设备连接同一 Wi-Fi 后，先在电脑浏览器打开接收页，再在手机浏览器打开发送页。输入访问码即可发送文本或上传 JPG 照片。按 `Ctrl+C` 停止服务。

新项目默认使用端口 `8766`，可与原项目默认使用的 `8765` 端口同时运行。若需更换端口，可运行 `python server.py --port 9000`。如果希望关闭终端后服务仍运行，可执行 `python start_background.py`；该后台启动脚本使用默认端口 `8766`。

## 文本与照片

手机发送的最新文本会显示在电脑接收页，可一键复制。新文本会覆盖旧文本；文本只保存在程序内存中，单条最多 64 KiB。

手机可一次选择多张 `.jpg` / `.jpeg` 照片，每张最多 20 MiB，每批最多 30 张、合计 150 MiB。电脑接收页可下载单张照片，或一键生成并下载 PDF。每张照片占一页，按照片方向适配 A4 页面，常见的 EXIF 旋转会被保留。照片按上传顺序保存在 `uploads/<批次编号>/`，PDF 也保存在该目录。点击“开始新批次”后，旧批次文件仍留在电脑上。

当前仅接收 JPG 照片，不自动转换 HEIC 或 PNG。PDF 生成在电脑本地完成。

## 连接与隐私

两台设备必须能在局域网内互访。访客 Wi-Fi 或开启客户端隔离的网络可能阻止连接；也可以让电脑连接手机热点。如果自动显示的手机网址用了错误地址，在电脑运行 `ipconfig` 查找当前 WLAN 的 IPv4 地址，然后运行 `python server.py --lan-ip 该地址`。Windows 防火墙也需要允许 Python 在当前网络类型上接收连接。

访问码每次启动都会重新生成。手机网页通过普通 HTTP 传输，文本和照片不会加密，请在可信的局域网中使用。接收页及下载接口仅允许从电脑本机访问。照片和 PDF 保存在磁盘上，停止服务后不会自动删除。
