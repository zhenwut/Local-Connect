# Local Connect

在手机和电脑之间传送文本和各类文件，并在电脑上按组转换、合并 PDF。电脑需要 Python 3.10+；手机只需浏览器。二维码库内置，PDF 功能使用 Pillow 和 pypdf。

## 启动与扫码

首次使用时，在项目目录安装依赖：

```powershell
python -m pip install --target .deps -r requirements.txt
```

日常启动时，Windows 上直接双击项目目录里的 [`start_local_connect.cmd`](start_local_connect.cmd)。脚本会切换到项目目录，运行 `python server.py`；服务运行期间请保持窗口打开。若启动失败，窗口会停留以显示错误。也可以在终端运行：

```powershell
python server.py
```

电脑浏览器打开终端显示的 `http://localhost:8766/receiver`。程序启动时会尝试开启 Windows 移动热点：

1. 电脑接收页显示第一个二维码。用手机相机扫描并确认加入电脑热点。
2. 检测到手机接入后，电脑页面自动切换为第二个二维码。再次扫描，手机浏览器打开传输页，访问码自动带入，无需输入。

Wi-Fi 二维码只能连接热点；手机系统不会在加入 Wi-Fi 后自动打开本地网页，因此需要再扫一次。部分扫码应用不支持 Wi-Fi 二维码，可以在手机 Wi-Fi 设置中手动选择页面显示的热点名称，随后扫描第二个码。若连接已成功但页面尚未切换，请稍等几秒。

电脑页的两节点时间线会在检测到手机加入热点后点亮第一步；手机通过第二个二维码打开网页后，连接线用约 2.8 秒填满，再点亮第二步。二维码与连接文字会按状态更新，时间线保留已完成进度，不会因短暂状态回退重新播放。手动连接模式不显示扫码时间线。

如果热点不可用，电脑页面会显示原有的手机网址和访问码。此时手机与电脑需接入可以相互访问的同一网络；公寓网络若开启客户端隔离，手动方式仍可能无法连接。Windows 防火墙也必须允许 Python 接收 TCP 8766 端口的连接。手机若提示该热点没有互联网，选择保持连接。

电脑接收页控制本次服务的生命周期。关闭所有电脑接收页后，经过约 8 秒宽限期，服务会自动退出，并关闭本次连接使用的电脑热点；手机发送页关闭不会结束电脑服务。刷新接收页有短暂宽限，多个接收页只关闭其中一个时仍可继续使用。浏览器异常退出时，服务通过连接断开检测退出，可能稍有延迟。

每次打开或刷新电脑接收页，文本、文件卡片和 PDF 容器都会自动清空，不需要“新批次”按钮；已经收到的文件继续保存在电脑磁盘上。服务结束后，再次使用需重新运行 `python server.py` 或 `python start_background.py`，然后打开电脑接收页。还没有打开过接收页时，服务会等待你打开。

也可按 `Ctrl+C` 停止前台服务；此方式只关闭程序自己开启的热点。`python start_background.py` 可在后台启动默认端口服务，其退出同样由电脑接收页控制。

默认端口为 `8766`，可用 `python server.py --port 9000` 修改。若手动模式显示的电脑地址有误，可用 `python server.py --lan-ip 电脑IPv4地址` 指定。原项目默认使用的 `8765` 端口不会冲突。

如果手机已连接电脑热点，但第二个二维码打开网页超时，请保持服务运行，并在管理员 PowerShell 中进入项目目录执行一次：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\setup_hotspot_firewall.ps1
```

这条规则只允许热点网段访问当前 Python 程序的 TCP 8766 端口。默认热点地址为 `192.168.137.1/24`；若电脑接收页显示的地址不同，使用 `-HotspotAddress 实际地址 -PrefixLength 实际前缀长度` 指定，端口变化则使用 `-Port`。Python 安装位置变化后需要重新执行。它不会关闭 Windows 防火墙。

## 传输

手机发送的最新文本显示在电脑接收页，可一键复制。手机与电脑的文本区均显示字符数（包含空格和换行，普通 emoji 算一个字符）。文本只保存在程序内存中，单条最大 64 KiB。

手机可一次选择多个任意格式文件，包括图片、音频、视频、PDF、Word、Excel、PPT、压缩包等；选中后自动逐个上传，也可在上传期间继续添加文件。单个文件最大 2 GiB，每次接收最多 100 个、合计 10 GiB。上传时逐个显示进度；失败后显示“重试未完成的文件”，修正访问码后也会自动继续。服务分块写入磁盘，不会把整个视频一次读进内存。

电脑接收页为每个文件显示独立卡片，点击卡片任意非勾选区域即可下载，保留中文文件名；同名文件分别保存，不会覆盖。JPG、PNG、GIF、WebP、BMP、AVIF 等浏览器可解码的图片铺满卡片预览区（必要时裁切边缘），只显示图片与名称。圆角勾选框悬浮在左上角，与卡片边缘保留间距；PDF 容器的勾选框使用相同样式。其他文件显示对应格式图标、名称和大小。HEIC、TIFF、SVG 等仍可完整传输，但暂以文件图标显示；损坏或无法解码的预览会自动回退为图标卡片。

电脑接收页在宽屏上将连接二维码放在顶部，接收文本放在左侧，文件放在右侧；窄窗口改为纵向排列。手机发送页采用纵向布局，将自动上传入口放在文本区前面。两端使用同一套本地 CSS，不依赖外部字体或界面资源。

文件保存在 `uploads/files-<批次编号>/<文件编号>/<文件名>`。重新打开接收页或重启服务后，旧文件仍在磁盘上，页面列表只展示当前接收记录。

## PDF 容器与一键下载

点击接收区域的“＋ PDF 容器”，依次创建 `pdf1`、`pdf2` 等容器。删除后会复用最小空缺编号，已有容器和自定义名称保持不变。已有空容器时，必须先加入文件才能继续创建。

- 将已上传的文件卡片拖入容器；可先勾选多个文件再一起拖动。文件按加入顺序排列。
- 图片加入容器后显示缩略图；可在容器内拖动缩略图调整 PDF 页序。每张缩略图右下角的 `↻` 每按一次顺时针旋转 90°，预览、单独下载和 ZIP 内的 PDF 都使用该角度。TIFF 缩略图显示首页，旋转会应用到全部页。
- 容器装入文件后只显示名称、成员内容和“下载 PDF”入口；空容器显示拖入提示。
- PDF 容器的下载入口固定在卡片最下方，即使同一行其他文件卡片更高也不会悬在中间。
- 一个容器只接受同一格式，JPG/JPEG/JFIF 视为同类，TIF/TIFF、HTM/HTML 也合并处理；DOC 和 DOCX 等不同扩展名分别放置。
- 点击容器主体，转换全部内容并下载一个 PDF。单击顶部名称可重命名，Enter 或失焦保存，Escape 取消。
- 点击右上角 `×` 移除容器，原文件返回列表；成员旁的 `↗` 可单独移出。也可把成员拖到容器外恢复为原文件，或拖到另一个同格式容器。
- 区域右下角“一键下载 ZIP”包含所有未分组的原文件，以及每个非空容器转换后的 PDF；不会再重复加入容器里的原文件。同名文件自动加编号保留。
- 勾选文件或 PDF 容器后，按钮变为“下载选中”，ZIP 只包含勾选项；选中的容器以转换后的 PDF 放入。取消全部勾选后恢复下载全部，旁边同时显示选中项数量和原文件大小。
- 总大小显示所有上传原文件的大小，分组不会重复计数；转换完成后显示实际 PDF 或 ZIP 下载大小。下载使用点击时的文件快照，后来上传的文件在下次下载中包含。

支持的转换格式：

| 输入 | 本地转换方式 |
| --- | --- |
| JPG/JPEG/JFIF、PNG、BMP、GIF、WebP、AVIF、TIF/TIFF | Pillow；每张图片一页，自动处理方向和透明背景。TIFF 导出所有页，动图取第一帧。 |
| DOC、DOCX | 已安装并可正常使用的 Microsoft Word，保留完整文档排版。 |
| XLS、XLSX | Microsoft Excel，按工作簿打印设置导出所有工作表。 |
| PPT、PPTX | Microsoft PowerPoint，导出所有幻灯片。 |
| HTML、HTM | 已安装的 Chrome 或 Edge，导出静态 HTML；保留内联样式和内嵌图片，不加载外部资源或运行脚本。 |
| PDF | 合并所有页。加密文件需先移除密码。 |

范围参考 iLovePDF 的 [JPG](https://www.ilovepdf.com/jpg_to_pdf)、[Word](https://www.ilovepdf.com/word_to_pdf)、[Excel](https://www.ilovepdf.com/excel_to_pdf)、[PowerPoint](https://www.ilovepdf.com/powerpoint_to_pdf)、[HTML](https://www.ilovepdf.com/html-to-pdf) 转 PDF 工具，并扩展了常见图片格式和 PDF 合并。文件在电脑本地转换，不上传到这些网站。其他格式仍可原样传输与下载。

每个容器最多 500 MiB、500 页；单张图片最多 4000 万像素，HTML 单个最多 20 MiB。Office 应用必须已完成首次启动和授权；被占用、文件损坏、需要密码或转换超时会显示错误，原文件保留。转换后的文件和 ZIP 保存在 `uploads/exports-<批次编号>/`，相同分组再次下载可复用已生成的 PDF。

## 连接安全

每次启动都会生成新访问码。第二个二维码只在电脑本机接收页显示，访问码放在网址的 `#` 片段中，不随网页请求发送；手机页面读取后会从地址栏移除。传输本身使用局域网 HTTP，适合可信网络。电脑接收页、连接信息及下载接口仅允许本机访问。

## 测试

```powershell
python -m unittest discover -s tests -v
```

自动测试不会真正开启热点；热点与手机扫码需要在实际设备上验证。

已安装 Chrome 和 Node.js 时，可运行 `node tests/browser_smoke.cjs`，使用独立临时服务检查上传、预览、字符数、PDF 容器拖入/格式限制/重命名/删除、PDF 与 ZIP 下载、刷新清空、多标签页和关闭后自动停服。桌面、窄屏与手机截图保存在 `.ui-artifacts/`，测试不会改动热点。

关闭 Office 应用后，可运行 `python tests/conversion_smoke.py`，用临时样例检查六种 Office 格式及 HTML 的完整多页转换。
